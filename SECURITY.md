# Security Policy — Crystal RV

## Reporting a Vulnerability

If you discover a security vulnerability on [crystalrv.com](https://crystalrv.com), please report it responsibly. We take the security of our site and our customers' data seriously.

### How to Report

Please **do not** create a public GitHub issue for security vulnerabilities.

Email us directly:

📧 **info@crystalrv.com**  
Subject: `[SECURITY] Brief description of the issue`

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact or attack scenario
- Your contact information (optional)

### Response Timeline

- **Acknowledgment:** Within 3 business days
- **Resolution:** Within 14 days for confirmed issues (depending on severity)
- **Notification:** We will let you know when the fix is deployed

### Scope

This policy covers:
- `crystalrv.com` and all subdomains (e.g., `test.crystalrv.com`)
- Contact and inquiry forms
- Newsletter signup
- Any user-facing data collection

### Out of Scope

- Third-party platforms: Wheelbase, Google Maps, Google Analytics, Mobilitas, Lloyd's of London
- Denial-of-service attacks
- Social engineering or phishing attempts
- Vulnerabilities in browsers or operating systems
